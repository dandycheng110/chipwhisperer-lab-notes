# 現成替代方案盤點：台灣開店 SaaS、LINE「+1」團購整單工具、超商賣貨服務與冷鏈運費（2025–2026）

> 研究方法註記（重要）：本次工作階段的 WebFetch 對所有網域都 DNS 解析失敗，shopline.tw 也被 egress proxy 拒絕連線，所以**沒有逐頁讀全文**。以下數字全部取自搜尋引擎對所列網頁的摘要，每條都附上該摘要對應的網址。如果搜尋摘要沒有明確指出出自哪一篇，會標「（搜尋摘要，出處為其中之一）」。多數價格來自第三方比較文，彼此常有出入，衝突與日期已逐條標註。今天是 2026-10-19。報價前建議到官網抽查。

## 一、台灣開店 SaaS（SHOPLINE、CYBERBIZ、91APP、WACA、EasyStore、Shopify、Meepshop、1Shop、BOUTIR）：價格、抽成、方案門檻、冷鏈與 LINE 整合

### Takeaway
以月營業額幾十萬元的小店來看，主流開店平台的軟體成本大約每月 NT$1,400 到 NT$10,000 以上：
- SHOPLINE 最貴：年費 NT$40,000 起，另收開通費 NT$5,000，再加 GMV 1.5–2% 流量維護費。
- CYBERBIZ：年費 NT$27,000 起，加 1% GMV。
- WACA、EasyStore、1Shop：平台抽成為 0% 或 1%，WACA 有 0 元方案。
- 91APP：客製報價，不適合小店。

下列功能多半要另外串接金物流（綠界、PayNow）、加購模組或升級方案，沒有哪一家內建全部：冷凍超取、LINE 收單、揀貨／進銷存。主流開店平台都**沒有**內建「LINE 群組聊天室 +1 自動成單」。SHOPLINE 的 LINE 功能屬於連結式下單、直播關鍵字 +1，以及 LINE 社群關鍵字回覆。

### Inferences
- **含稅與未稅混用**：CYBERBIZ 官方頁的「高手版+ $68,040」剛好等於 64,800×1.05；某文的「進階版+ ≈NT$4,113/月」等於 47,000×1.05÷12；EasyStore 的「NT$1,469」等於 1,399×1.05。可見第三方文多半列未稅價，官方頁可能列含稅價。製表時要統一口徑。
- **抽成型平台規模越大越貴**：月 GMV 幾十萬的店，SHOPLINE 的 2% 流量費很快就超過年費攤提。例如 GMV NT$36 萬 → 流量費 NT$7,200/月，大於 NT$3,333/月的年費攤提。固定費或 0 抽成的平台（WACA、EasyStore、1Shop 無限方案）比較划算。
- **透過開店平台做冷凍超取要走 B2C 大宗寄倉**：綠界或 PayNow 都要申請、跑測試單、預儲點數（見第四節）。對小賣家來說，門檻比直接用賣貨便／好賣+ 這類 C2C 冷凍店到店高。
- **LINE 收單方式不同**：SHOPLINE、EasyStore 讓顧客點連結進商店下單（連結式），不會去解析群組聊天裡的「+1」或自由文字。這正是 +1 整單工具和客製 AI 整單切入的地方。

### Inferences
- 一個月幾百單的海鮮店，一定會超過飛比免費版的 30 單／NT$10,000 上限。若「原本的 App」是這類工具，付費方案大約 NT$800–1,400/月；若是 OrderPally 含 LINE 群組的方案，則約 NT$4,000–4,500/月。
- 現成 +1 工具大多要求固定格式（「+1」「關鍵字+1」或記事本貼文留言）。如果團員習慣打「蝦仁兩包、干貝一盒、週五面交」這種自由文字，就得靠 AI 解析。貼文「AI 直接把群組訂單整理成一張一張」正好補這個縫。不過愛+1 已推出「進階 AI」方案，jidou 也在做，這不是獨家能力。
- 貼文「群組打『菜單』自動跳商品」要靠 Messaging API 機器人在**LINE 群組**裡用 reply 回覆，回覆不算訊息量、成本低。如果店家用的是 **LINE 社群（OpenChat）**，官方 API 做不到。這是判斷該客製案可行性的關鍵前提。
- 客製版若要對每位買家**主動推播**訂單確認或取貨通知，幾百單很快超過每月 200 則免費額度，就得付中用量方案：2026-11 起 NT$1,000/月（未稅）。這是「299 起」報價之外的隱藏成本。

### Gaps
- 未查到飛比+1、樂樂BUY、OrderPally 是否支援冷凍超取，或能匯出賣貨便／好賣+ 格式。愛+1 有列出賣貨便／好賣選項，但沒說冷凍。
- 愛+1「進階 AI」方案實際做什麼，未查到。
- Chia 付費細節，以及點點團購、LiveShop 的價格，都未查到。
- LINE 揪團在 2026 年是否還在營運，未證實。
- 各工具的「+1 擷取／通知穩定度」沒有獨立實測，只有廠商說法。

## 五、LINE 群組食品賣家（海鮮團購、團媽）的痛點

### Takeaway
痛點集中在下面幾類。多數量化說法（如「省 80% 時間」）來自廠商，沒有獨立驗證；海鮮店主本人的第一手心得也很少。
- **接單**：+1 漏看、算錯錢；補單、改單、追問把留言洗掉；截單界線難劃。
- **對帳**：匯款要逐筆對「末五碼＋金額」，常對到深夜。
- **海鮮特有**：臨時售罄、現貨與預購混雜。
- **工具面**：LINE Notify 停用讓舊系統通知斷鏈；平台抽成；業績與訂單資料留在廠商後台、不透明。

- **工具綁定**：OrderPally 的 LINE 群組收單要用商城創始者的 LINE 帳號綁定，綁定後無法解除 — [OrderPally LINE 群組收單](https://orderpally.com/linegroup/)
- **B2B 對照案例**：食品代工廠在雙十一差點在 LINE 群組裡崩潰 — [vocus](https://vocus.cc/article/69bff70ffd897800014427cf)；LINE 群組接單改用 AI 寫入 ERP 的案例 — [jidou 2026-04](https://jidou.ai/blog/2026-04-20-line-group-order-real-case)

### Inferences
- 貼文客製功能和痛點一一對應：
  - 「AI 把群組訂單整理成一張一張」→ 漏單、算錯、自由文字。
  - 「轉帳對末五碼」→ 對帳到深夜。
  - 「揀貨單、出貨單、賣貨便一鍵匯出」→ 分貨與出貨。
  - 「庫存、掃條碼進貨」→ 售罄與超賣。
- 「被別人的 App 綁住」的具體樣態：資料與業績在廠商後台、通知服務被上游（LINE Notify）切斷、帳號綁定不可解除、抽成隨營業額成長。這些都是「想換自己的網站」的合理動機，但沒有找到該海鮮店本人的說法。

### Gaps
- 沒找到 Dcard、PTT、Threads 上**海鮮團購主本人**談系統、對帳的第一手貼文，多數痛點描述出自工具廠商。
- 沒有直接證據顯示團購主抱怨「資料匯不出來」或「換系統很難」，以上屬推論。

## 六、綜合：功能覆蓋對照、成本試算、「原本用別人的 App」推測與客製化補上的縫

### Takeaway
貼文列的每項功能，現成方案「都有人做」，但分散在三類工具裡：
- 開店 SaaS：購物車、會員、購物金、報表、冷凍物流串接。
- +1 整單工具：LINE 群組 +1、催款、批次出貨。
- 超商 C2C：便宜的冷凍運費和批次匯入。

**找不到任何單一現成產品**同時做到這幾件事：
- LINE 群組自由文字 AI 整單；
- 賣貨便冷凍批次匯出；
- 轉帳末五碼對帳；
- 條碼進貨＋毛利報表；
- 而且不抽成。

這就是客製網站補上的縫。「原本用別人的 App」最可能是 +1 整單系統（飛比+1／愛+1／樂樂BUY／OrderPally 這類，月費約 NT$800–4,500），而不是 SHOPLINE 這種年費 4 萬起的平台。但貼文沒指名，這是推論。

- **客製版實際補上的縫**：
  1. 一套系統整合 +1 收單、商店、會員行銷、出貨、庫存、報表。現成方案要「+1 工具＋開店 SaaS＋超商 C2C」三套拼起來，資料分散。
  2. 自由文字 AI 整單，不必要求客人照格式打 +1。
  3. 用「轉帳末五碼」比對，取代 ATM 虛擬帳號每筆 NT$17–20 的金流費，也避開信用卡 2–3.5%。對幾百單、客單上千的海鮮團，每月可省數千元。
  4. 直接產生賣貨便（理論上也可做好賣+）批次匯入檔，用 C2C 冷凍 NT$99–129 的運費，避開 B2C 大宗寄倉的申請、測試單和預儲點數。
  5. 不抽成，資料在店家手上。
  6. 條碼進貨＋毛利報表。海鮮進價波動大（推測），毛利追蹤有實際價值；一般 +1 工具大多沒有這項。
- **「原本用別人的 App」推測排序**：
  1. **+1 整單系統**（飛比+1、愛+1、樂樂BUY、OrderPally、Chia、點點團購這類）——最符合「LINE 群組開團、一個月幾百單、叫它 App」。
  2. 開店 SaaS 的 LINE 功能（SHOPLINE、EasyStore LINE 訂購單）——可能性較低，因為年費高，且不解析群組 +1。
  3. 直接用賣貨便／好賣+ 賣場——客製版保留了「賣貨便匯出」，暗示賣貨便很可能本來就是物流層，持續使用。
- **客製方案相對的風險**（簡述，細節留給風險章節）：
  - 賣貨便匯入檔是含 VBA 巨集的 .xlsm，而且「僅限取貨付款」，格式或規則一變就要跟著改。
  - LINE OA 主動推播會超出免費額度。
  - LINE 社群（OpenChat）無法放 bot。
  - 沒有正式金流，只能靠轉帳與取貨付款，信用卡客群會流失。

### Gaps
- 貼文沒寫出「原本的 App」名稱，以上只是推論。
- 「299 起」是月費、一次性還是單項功能價，未知（不在本研究範圍，留給其他章節）。
- 該海鮮店的客單價、單量結構（面交、超商、宅配比例）未知，成本試算是假設值。
- 優惠碼、面交、毛利報表在各平台的支援度，本次沒有逐一查證。
